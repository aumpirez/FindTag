# 📡 BLE Radar · iSearching

Localizador Bluetooth para tag iSearching / iFindU con reconexión automática.

## 🚀 Cómo subir a GitHub Pages

1. Crea un repositorio en GitHub (ej. `ble-radar`)
2. Sube los 4 archivos: `index.html`, `manifest.json`, `icon.svg`, `README.md`
3. Ve a **Settings → Pages → Branch: main → / (root)**
4. En 1-2 minutos tu URL estará lista: `https://tuusuario.github.io/ble-radar`

## ✅ Funciones

- 🔗 Conexión BLE con tag iSearching / iFindU
- 🔄 Reconexión automática al perder señal (hasta 10 intentos)
- 🔔 Notificaciones del sistema al desconectar y reconectar
- 🔊 Hacer sonar el tag físico (High Alert BLE)
- 📡 Radar de señal RSSI en tiempo real
- 🔔 Beeper del celular: lento lejos, rápido cerca
- 🧭 Brújula de dirección aproximada
- 🔋 Nivel de batería del tag
- 📲 Instalable como app (PWA)

## ⚠️ Requisitos

- Chrome o Edge en Android
- HTTPS (GitHub Pages lo provee automáticamente)
